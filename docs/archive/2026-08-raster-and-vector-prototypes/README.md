# Raster and vector prototype archive

These documents record the path from the original raster application through the rejected camera-aligned vector-cache prototype. They are retained as historical evidence, not as current implementation direction.

For current work, start with [`PROJECT_STATE.md`](../../../PROJECT_STATE.md) and the production handoff it links. In particular, [`PROTOTYPE_EXIT.md`](../../../PROTOTYPE_EXIT.md) supersedes the plans and interim handoffs in this directory.

## Contents

- `INITIAL_RESEARCH.md`, `FINDINGS.md`, and `DEMO.md`: original product brief, raster-era findings, and demo script.
- `TLDraw_CLEAN_ROOM_NOTES.md`: historical external-design research and licensing notes.
- `V2_INITIAL_SPEC.md`, `V2_PHASE1_FINDINGS.md`, `V2_PHASE2_PROTOTYPE_PLAN.md`, and `V2_PHASE2_PROTOTYPE_FINDINGS.md`: early vector-canvas phases.
- `INTERACTIVE_PAN_BENCHMARK.md` and `INTERACTIVE_PAN_BENCHMARK_FINDINGS.md`: first interactive cache experiment.
- `VECTOR_CANVAS_SECOND_OPINION_BRIEF.md`, `ORACLE_REVIEW_REQUEST.md`, and `DECISIVE_VECTOR_CACHE_PROTOTYPE_PLAN.md`: review inputs and the final prototype plan.
- `CONTINUATION_HANDOFF_2026_08_12.md` and `CONTINUATION_HANDOFF_2026_08_12_EVENING.md`: superseded interim handoffs.

Raw logs, review packets, and benchmark receipts remain in their existing evidence directories so references and provenance stay intact.
